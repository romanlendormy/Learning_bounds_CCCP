# scratch/

Dossier pour les scripts `.sh` d'exploration ponctuelle (bench, compare, check,
debug, probe, calibrate...) — tout ce qui n'entraîne pas le GNN et ne lance
pas la campagne test_paper/test_paper_trillium.

Objectif : éviter que la racine du dépôt se re-remplisse de dizaines de
scripts jetables comme avant le nettoyage de septembre 2026. Ce dossier
peut grossir librement — il est isolé, facile à auditer ou vider en bloc
plus tard sans toucher au reste du dépôt.
